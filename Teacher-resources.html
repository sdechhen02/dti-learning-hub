Resource 01

Lesson Plan

A structured lesson for introducing Digital Number Systems.

📋

Digital Number Systems

Digital Technology and Innovation · Class IX

SUBJECT DTI
CLASS IX
DURATION 60 minutes

Teaching methods

Explanation, demonstration, questioning, pair work and individual practice.

Teaching materials

Whiteboard, markers, number-system reference chart, presentation slides, worksheets and a computer or projector, if available.

Learning objectives

By the end of the lesson, students will be able to:

  1. Identify decimal, binary, octal and hexadecimal number systems and state their bases.
  2. List the valid symbols used in each number system.
  3. Explain positional value using a simple numerical example.
  4. Solve introductory number-system conversion questions using the methods taught in the lesson.

Teaching and learning procedure

Time Teacher activities Expected student activities
5 min Ask which number system students normally use when counting. Write 25 on the board and ask whether computers represent numbers in the same way. Share prior knowledge and suggest how computers represent numbers.
10 min Introduce the four number systems and explain their bases and allowed symbols. Listen, answer questions and complete a comparison table.
10 min Explain positional value using 247 in decimal. Show that each position represents a power of 10. Identify the hundreds, tens and ones positions.
15 min Demonstrate binary-to-octal conversion by grouping digits and binary-to-decimal conversion using place values. Follow the worked examples and copy the steps.
12 min Distribute practice questions and ask students to solve them in pairs and explain their methods. Solve questions and discuss their working.
5 min Give a short individual assessment. Answer the questions independently.
3 min Summarise the number systems and review common mistakes. State one important concept learned.

Assessment questions

  1. What is the base of the binary number system?
  2. Which digits are used in the octal number system?
  3. What does the base of a number system tell us?
  4. Convert 10110₂ to octal.
  5. Convert 110101₂ to decimal.
Show expected answers
  1. 2
  2. Digits 0–7
  3. The number of distinct digit symbols available in the system.
  4. 26₈
  5. 53₁₀

Differentiation

For students who need support

  • Provide a table of bases and symbols.
  • Demonstrate one conversion at a time.
  • Provide partially completed examples.

For students at the expected level

  • Provide mixed identification and conversion exercises.
  • Ask students to explain their working to a partner.

For students needing a challenge

  • Explain why three binary digits correspond to one octal digit.
  • Compare two methods of converting a number.
Resource 02

Teacher's Guide and Notes

Reference notes to support explanations and classroom teaching.

1. Introduction to number systems

A number system is a way of representing numbers using a set of symbols and rules.

In digital technology, number systems are important because computers represent information using binary digits. Octal and hexadecimal can provide shorter ways of writing binary values.

2. Comparison of the four number systems

Number system Base Symbols used Common programming prefix
Decimal 10 0–9 Usually none
Binary 2 0 and 1 0b
Octal 8 0–7 0o
Hexadecimal 16 0–9 and A–F 0x

Teaching note: The prefixes above are common programming conventions. Teach them as prefixes only if they are included in the assigned textbook content.

Hexadecimal symbols

ADecimal 10
BDecimal 11
CDecimal 12
DDecimal 13
EDecimal 14
FDecimal 15

3. Understanding positional value

The value of a digit depends on its position in a number. Consider the decimal number 247.

247 = (2 × 100) + (4 × 10) + (7 × 1)
247 = 2 × 10² + 4 × 10¹ + 7 × 10⁰

The digit 2 represents two hundreds, 4 represents four tens, and 7 represents seven ones. The same principle applies to other positional number systems.

  • Binary uses powers of 2.
  • Octal uses powers of 8.
  • Hexadecimal uses powers of 16.

4. Common student errors

Common error How the teacher can address it
Using the digit 2 in a binary number Remind students that binary uses only 0 and 1.
Using 8 or 9 in an octal number Review the allowed symbols from 0 to 7.
Forgetting the base of the final answer Ask students to write the base as a subscript.
Grouping binary digits incorrectly Demonstrate grouping from the right-hand side.
Forgetting leading zeros during grouping Explain that adding zeros to the left does not change a number's value.
Making arithmetic errors Encourage students to show every step.

5. Questions for classroom discussion

  1. Why do we use different number systems?
  2. Why does binary use only two digits?
  3. How is the base related to the symbols used?
  4. Why is the digit 8 not permitted in an octal number?
  5. Why are hexadecimal numbers useful for writing long binary values?

05 Understanding Positional Value

Consider 247 in decimal:

  • 2 is in the hundreds position.
  • 4 is in the tens position.
  • 7 is in the ones position.
247 = 200 + 40 + 7
06 Binary to Octal

Convert 10110₂ to octal.

Step 1: Write the binary number: 10110.

Step 2: Group three digits from the right: 10 110.

Step 3: Add a zero to the left group: 010 110.

Step 4: Convert each group.

  • 010₂ = 2
  • 110₂ = 6
10110₂ = 26₈
07 Binary to Decimal

Convert 110101₂ to decimal.

1 × 2⁵ + 1 × 2⁴ + 0 × 2³ + 1 × 2² + 0 × 2¹ + 1 × 2⁰
32 + 16 + 0 + 4 + 0 + 1 = 53
Answer: 110101₂ = 53₁₀

  2. Which symbols are used in hexadecimal?
  3. Convert 100101₂ to decimal.
  4. Convert 111001₂ to octal.
09 Lesson Summary
  • Decimal uses base 10.
  • Binary uses base 2.
  • Octal uses base 8.
  • Hexadecimal uses base 16.
  • The base determines available symbols and positional values.
