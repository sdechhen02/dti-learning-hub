1 What Is Data Representation?

Data representation is the way information is expressed, stored and processed in a computer.

Computers work with different types of information, such as:

📝 Text Letters, words and sentences.
🔢 Numbers Quantities and calculations.
🖼️ Images Photographs and drawings.
🎵 Audio Recorded voices and music.
🎬 Video Moving pictures and recordings.

Although these types of information look different to us, computers represent them internally using binary digits, called bits.

Example: A student types their name

SONAM

01010011 01001111
01001110 01000001 01001101

Text is represented using digital codes.

Remember: Computers use digital codes to represent text. The binary sequence above is illustrative; actual codes depend on the character encoding used.
Think about sending a photo.

Your phone displays the photo as an image, but the computer stores and processes its information digitally. The same idea applies to text, sound and video.

2 What Is a Number System?

A number system is a method of representing numbers using a set of symbols and rules. The base tells us how many different digits are available in that system.

Number System Base Symbols Used Example
Decimal 10 0–9 245₁₀
Binary 2 0 and 1 1011₂
Octal 8 0–7 57₈
Hexadecimal 16 0–9 and A–F 2F₁₆
Decimal Base 10 Digits 0–9
Binary Base 2 Digits 0 and 1
Octal Base 8 Digits 0–7
Hexadecimal Base 16 Digits 0–9 and A–F
Did you know? Each octal digit corresponds to three binary bits, while each hexadecimal digit corresponds to four binary bits.
Example: The hexadecimal digit A represents decimal 10 and binary 1010.
A₁₆ = 10₁₀ = 1010₂

3 Understanding Place Value

In a positional number system, the value of a digit depends on its position. Each position represents a power of the system's base.

Decimal Example: 352

352 = (3 × 100) + (5 × 10) + (2 × 1)

The place values are powers of 10:

10², 10¹, 10⁰

300 + 50 + 2 = 352

Binary Example: 1011₂

1011₂ = (1 × 8) + (0 × 4) + (1 × 2) + (1 × 1)
1011₂ = 11₁₀

The place values are powers of 2:

2³, 2², 2¹, 2⁰
What is a subscript? The small number written below a number, such as the 2 in 1011₂, identifies its base.

Try It Yourself

What is the decimal value of 110₂? Think about the place values before revealing the answer.

110₂ = (1 × 4) + (1 × 2) + (0 × 1) = 6₁₀
The answer is 6 in decimal.

4 Why Do Computers Use Binary?

Computers use electronic circuits that can represent two states, such as ON and OFF. These states can be represented using binary digits.

1 ON

A state represented by binary 1.

0 OFF

A state represented by binary 0.

💡 What Is a Bit?

A bit is a single binary digit.

0 or 1 = 1 bit

💻 What Is a Byte?

A byte contains eight bits.

10101010 = 8 bits
Remember: Binary is useful because digital circuits can reliably distinguish between two states. Real computer hardware is more complex, but binary provides a practical way to represent and process information.
