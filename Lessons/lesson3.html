02

Introduction to the Octal Number System

Understand the base and digits used in octal numbers.

The octal number system is a number system with a base of 8. It uses eight digits, from 0 to 7, to represent numbers.

Octal digits: 0, 1, 2, 3, 4, 5, 6, 7

Unlike the decimal system, which uses ten digits, the octal system does not use the digits 8 and 9. Each position in an octal number represents a power of 8.

Example of a valid octal number

725₈

This is valid because all its digits are between 0 and 7.

Example of an invalid octal number

728₈

This is invalid because the digit 8 is not allowed in base 8.

Remember The small subscript 8 indicates that the number is written in the octal number system.

Place values in the octal system

Starting from the right, the place values are powers of 8: \(8^0, 8^1, 8^2, 8^3\), and so on.

Position Third from right Second from right Rightmost
Power of 8 8² 8¹ 8⁰
Place value 64 8 1

For example, the octal number 347₈ can be expanded as follows:

347₈ = (3 × 8²) + (4 × 8¹) + (7 × 8⁰)
= (3 × 64) + (4 × 8) + (7 × 1)
= 192 + 32 + 7
= 231₁₀
03

Converting Octal to Binary

Convert each octal digit into a group of three binary bits.

Binary uses only the digits 0 and 1. To convert an octal number to binary, replace each octal digit with its equivalent three-bit binary value.

Octal digit Binary equivalent Octal digit Binary equivalent
00004100
10015101
20106110
30117111

Worked Example 1: Convert 34₈ to binary

  1. Separate the octal digits: 3 and 4.
  2. Convert 3 into binary: 3 = 011.
  3. Convert 4 into binary: 4 = 100.
  4. Join the binary groups: 011100.
  5. Remove the unnecessary leading zero.
34₈ = 011 100₂ = 11100₂

Worked Example 2: Convert 126₈ to binary

1 = 001
2 = 010
6 = 110

126₈ = 001 010 110₂
126₈ = 1010110₂
Conversion tip Always write three binary bits for each octal digit before joining the groups. You can remove leading zeros from the final answer.
04

Converting Octal to Decimal

Use powers of 8 to calculate the decimal value.

The decimal number system has a base of 10 and uses digits from 0 to 9. To convert an octal number to decimal, multiply each digit by its place value and add the results.

Method Start from the rightmost digit with \(8^0\). Move left using \(8^1\), \(8^2\), \(8^3\), and so on.

Worked Example 1: Convert 157₈ to decimal

Digit Place value Multiplication Result
18² = 641 × 6464
58¹ = 85 × 840
78⁰ = 17 × 17
157₈ = (1 × 64) + (5 × 8) + (7 × 1)
= 64 + 40 + 7
= 111₁₀

Worked Example 2: Convert 64₈ to decimal

64₈ = (6 × 8¹) + (4 × 8⁰)
= (6 × 8) + (4 × 1)
= 48 + 4
= 52₁₀
Common mistake Do not multiply by powers of 10 when converting octal to decimal. The place values must be powers of 8.
05

Converting Octal to Hexadecimal

Use binary as the bridge between the two number systems.

The hexadecimal number system has a base of 16. It uses digits 0–9 and letters A–F, where A represents 10, B represents 11, C represents 12, D represents 13, E represents 14, and F represents 15.

The easiest way to convert octal to hexadecimal is to convert the octal number to binary first, then convert the binary number to hexadecimal.

  1. Convert every octal digit into three binary bits.
  2. Group the binary digits into groups of four from the right.
  3. Add leading zeros to the left if a group has fewer than four bits.
  4. Convert each four-bit group into its hexadecimal equivalent.

Worked Example 1: Convert 17₈ to hexadecimal

Step 1: Convert octal to binary.
1 = 001 and 7 = 111
17₈ = 001111₂

Step 2: Group into four bits from the right.
001111₂ = 0000 1111₂

Step 3: Convert each group to hexadecimal.
0000 = 0 and 1111 = F

Answer: 17₈ = F₁₆

Worked Example 2: Convert 64₈ to hexadecimal

Step 1: Convert octal to binary.
6 = 110 and 4 = 100
64₈ = 110100₂

Step 2: Group into four bits from the right.
110100₂ = 0011 0100₂

Step 3: Convert each group to hexadecimal.
0011 = 3 and 0100 = 4

Answer: 64₈ = 34₁₆
Remember the grouping rule Use groups of three bits for octal and groups of four bits for hexadecimal.

Lesson Summary

Review the important points before moving to the next lesson.

  • The octal number system has a base of 8.
  • It uses the digits 0 to 7 only.
  • Octal to binary: convert each octal digit into three binary bits.
  • Octal to decimal: multiply each digit by its corresponding power of 8 and add the results.
  • Octal to hexadecimal: convert to binary, group into four bits, and convert each group to hexadecimal.
  • Always check that an octal number does not contain 8 or 9.
