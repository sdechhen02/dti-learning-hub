📘 Understanding Digital Number Systems

A number system is a way of representing numbers using a set of symbols and rules. Computers use number systems to store, process, and communicate data.

In Digital Technology and Innovation (DTI), four important number systems are binary, decimal, octal, and hexadecimal. Each system has a different base.

Remember: the small number written at the bottom right of a number, such as ₂ or ₁₆, tells you its number-system base.

01

Binary Number System

Base 2

The binary number system uses only two digits: 0 and 1. Computers use binary because digital circuits can represent two states, such as OFF and ON.

Digits used: 0, 1

Example

1011₂

This is a binary number. Its value in decimal is 11.

02

Decimal Number System

Base 10

The decimal number system is the number system we commonly use in everyday life. It uses ten digits, from 0 to 9.

Digits used: 0–9

Example

345₁₀

345 = (3 × 100) + (4 × 10) + (5 × 1)

03

Octal Number System

Base 8

The octal number system uses eight digits. It can represent binary numbers more compactly by grouping binary digits in sets of three.

Digits used: 0–7

Example

17₈

17₈ = (1 × 8) + (7 × 1) = 15₁₀

04

Hexadecimal Number System

Base 16

The hexadecimal number system uses sixteen symbols. It uses digits 0–9 and letters A–F, where A represents 10, B represents 11, and so on up to F, which represents 15.

Symbols used: 0–9 and A–F

Example

B₁₆

B₁₆ = 11₁₀

✏️ Worked Examples

Follow these steps to understand how number conversion works.

Example 1: Binary to Decimal

Convert 1101₂ to decimal.

Step 1: Write the powers of 2 from right to left.

2³, 2², 2¹, 2⁰

Step 2: Multiply each binary digit by its place value.

(1 × 8) + (1 × 4) + (0 × 2) + (1 × 1)

Step 3: Add the values.

8 + 4 + 0 + 1 = 13

Answer: 1101₂ = 13₁₀

Example 2: Decimal to Binary

Convert 13₁₀ to binary.

Divide the decimal number by 2 repeatedly and record each remainder.

13 ÷ 2 = 6 remainder 1

6 ÷ 2 = 3 remainder 0

3 ÷ 2 = 1 remainder 1

1 ÷ 2 = 0 remainder 1

Read the remainders from bottom to top.

Answer: 13₁₀ = 1101₂

Example 3: Binary to Octal

Convert 101110₂ to octal.

Step 1: Group the binary digits into sets of three from the right.

101 | 110

Step 2: Convert each group to its octal digit.

101₂ = 5₈

110₂ = 6₈

Answer: 101110₂ = 56₈

Example 4: Binary to Hexadecimal

Convert 10110110₂ to hexadecimal.

Step 1: Group the binary digits into sets of four from the right.

1011 | 0110

Step 2: Convert each group into a hexadecimal digit.

1011₂ = B₁₆

0110₂ = 6₁₆

Answer: 10110110₂ = B6₁₆

💡 Helpful Study Tips

Use these simple tips to make learning number systems easier.

📖

Understand the Bases

Remember that binary is base 2, decimal is base 10, octal is base 8, and hexadecimal is base 16.

✍️

Practise Step by Step

Write each conversion step clearly instead of trying to solve the whole question mentally.

🔢

Learn Place Values

Practise using powers of the base when converting a number to decimal.

🔄

Check Your Answers

Convert your result back to the original number system when possible to check your work.

💻

Connect Learning to Computers

Remember that computers represent and process digital information using binary values.

🎯

Practise Regularly

Start with simple conversions and gradually move to more challenging questions.
