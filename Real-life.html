What are digital number systems?

A number system is a way of representing numbers using symbols and rules. In digital technology, number systems help represent, store and process information.

Decimal is commonly used in everyday counting. Digital computers represent information using binary digits, 0 and 1. Octal and hexadecimal provide more compact ways of writing binary values.

Learning Beyond the Classroom

Where Are Number Systems Used?

Explore each example. Select “Discover how it works” to reveal an extra fact.

💻

1. Computers and Laptops

Computers represent data using binary. Text, pictures, instructions and other information are encoded into digital forms that computers can process.

1010₂ = 10₁₀
The binary number 1010 means 1 × 8 + 0 × 4 + 1 × 2 + 0 × 1 = 10. The small subscript identifies the number system's base.
📱

2. Smartphones

Smartphones process messages, photographs, applications and audio as digital information. Binary representation is fundamental to this processing.

Digital data: 0s and 1s
When you take a photograph, your phone processes and stores encoded image data. Hexadecimal can also help technicians inspect low-level digital values.
🎨

3. Digital Colours

Many screens represent colours using red, green and blue (RGB) components. Hexadecimal notation is a convenient way to write these component values.

Red: #FF0000
#FF0000 means red FF, green 00 and blue 00. Hexadecimal FF equals decimal 255, so the red component is at its maximum in this colour notation.
🌐

4. Websites and Programming

Web developers use hexadecimal colour codes to style headings, backgrounds, borders and buttons. Programmers also use hexadecimal to inspect digital values.

CSS: #8F1515
The colour code above contains three hexadecimal pairs: 8F for red, 15 for green and 15 for blue. Changing these pairs changes the displayed colour.
🖼️

5. Digital Images and Videos

Images and videos are represented as digital data. Pixel values and compressed media information are encoded so devices can store, edit and display them.

Bits → Encoded data
A digital image is not stored as one long list of visible colours. Its data is encoded according to an image format, and video formats may compress many frames to reduce size.
🧮

6. Calculators and Digital Devices

Electronic calculators accept numbers and perform calculations using digital circuits. People generally enter decimal numbers, while internal operations use digital representations.

Decimal: 25
Decimal 25 can be written as binary 11001, octal 31, or hexadecimal 19. They represent the same numerical value.
🧩

7. Octal Number System

Octal uses digits 0 to 7. Each octal digit corresponds to three binary bits, making it possible to write certain binary values more compactly.

17₈ = 15₁₀
Octal 17 equals 1 × 8 + 7 = 15 in decimal. Octal notation is also used to express file permissions in Unix-like operating systems.
🔐

8. Digital Data and Security

Digital systems store and communicate encoded information. Binary is fundamental, while hexadecimal makes long digital values easier for people to read.

Hexadecimal: 2F
Hexadecimal 2F equals decimal 47. Hexadecimal notation is useful in debugging and inspecting data, but a hexadecimal value alone does not provide security.

Did You Know?

One hexadecimal digit represents exactly four binary bits. For example, hexadecimal A is binary 1010 and decimal 10.

This makes hexadecimal useful for writing long binary values more compactly. Try entering A in the converter with hexadecimal selected!
